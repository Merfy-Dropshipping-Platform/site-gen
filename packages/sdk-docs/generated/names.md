# Имена полей секций

Поле настройки секции — в `settings` файла `section.json` и у типов блоков — называется именем из этого списка, вид поля — из столбца «Виды». Имя не из списка проверка при сохранении не пропускает и выводит ближайшее; для имён из раздела «Нет в словаре» — что вместо них. Тот же текст выводит `pnpm merfy section names`.

## Содержимое

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `heading` | `string` | Заголовок | Заголовок секции или блока; у «Страницы» — `<h1>` |
| `subheading` | `string` | Подзаголовок | Строка над или под заголовком |
| `text` | `text`, `richtext` | Текст | Основной текст секции или блока |
| `button-label` | `string` | Текст кнопки | Надпись на кнопке |
| `button-link` | `url` | Ссылка кнопки | Куда ведёт кнопка: страница магазина или свой адрес |
| `image` | `image` | Картинка | Картинка секции или блока |
| `images` | `image-pair` | Картинки | Две картинки: для компьютера и для телефона |
| `label` | `string` | Подпись | Подпись пункта, ссылки или значка |
| `link` | `url` | Ссылка | Куда ведёт пункт, карточка или картинка |
| `question` | `string` | Вопрос | Вопрос в блоке вопросов и ответов |
| `answer` | `richtext` | Ответ | Ответ на вопрос, текст с форматированием |
| `author` | `string` | Имя | Кто написал отзыв или цитату |
| `caption` | `string` | Подпись | Город, должность или товар под именем или картинкой |
| `rating` | `range` | Оценка | Звёзды отзыва, 0 — без звёзд |
| `video` | `url` | Видео | Адрес видео |
| `logo` | `image` | Логотип | Своя картинка логотипа в секции. Логотип магазина — настройка темы `logo-image` |
| `newsletter` | `toggle` | Рассылка | Показать форму подписки на рассылку |
| `menu` | `menu` | Меню | Меню магазина: в ревизии — id меню, в шаблоне — дерево `{ title, items }` |

## Вид

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `heading-size` | `select`, `radio` | Размер заголовка | Размер заголовка: варианты задаёт секция |
| `text-size` | `select`, `radio` | Размер текста | Размер основного текста: варианты задаёт секция |
| `align` | `alignment` | Выравнивание | Выравнивание текста: слева, по центру или справа |
| `content-position` | `select` | Где текст | Где текст поверх картинки: девять мест |
| `image-position` | `radio` | Картинка | Картинка слева или справа от текста |
| `height` | `radio`, `select` | Высота | Высота секции |
| `overlay` | `range` | Затемнение | Затемнение картинки под текстом, в процентах |
| `space` | `padding` | Отступы | Отступы секции сверху и снизу, в пикселях |
| `columns` | `range` | Колонки | Сколько карточек в ряд на компьютере |
| `aspect-ratio` | `select` | Пропорции | Пропорции картинок в сетке |
| `color-scheme` | `color-scheme` | Цветовая схема | Цветовая схема части секции: меню, карточек, плашки с текстом. Схема всей секции — общая настройка |
| `logo-position` | `select` | Положение логотипа | Где логотип в шапке: сверху слева, сверху в центре, слева или по центру |
| `menu-type` | `select` | Тип меню | Боковое, выпадающее или расширенное меню |

## Поведение

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `open-first` | `toggle` | Первый открыт | Первый вопрос раскрыт при загрузке |
| `autoplay` | `toggle` | Листать сами | Слайды меняются без нажатия |
| `interval` | `range` | Интервал | Секунд между слайдами; поле показано при `autoplay` |

## Нет в словаре

| Имена | Что вместо |
|---|---|
| `layout`, `variant`, `mode`, `view`, `design`, `style` | Секция другого вида — новая секция: её делает ИИ или автор. Мелкие отличия — поля `image-position`, `columns`, `height` |
| `color`, `colour`, `background`, `background-color`, `text-color` | Своего цвета у поля нет: цвет секции — общая настройка «Цветовая схема», цвет части секции — поле `color-scheme` |
| `font`, `font-family`, `font-size`, `font-weight`, `typography` | Шрифт и насыщенность — токены темы `font-heading` и `font-body`; размер — поля `heading-size` и `text-size` |
| `margin`, `padding-top`, `padding-bottom`, `gap`, `spacing` | Отступы секции — общая настройка «Отступы» в `wrapper`; внутри секции — классы словаря |
| `width`, `container`, `full-width` | Ширина секции будет общей настройкой секции; своего поля ширины у секции нет |
| `show-*`, `hide-*`, `visible`, `hidden` | Показать или скрыть часть секции — блок с `limit: 1`: его скрывают в конструкторе |
| `scheme`, `padding`, `sticky` | Общая настройка секции: в `settings` её не объявляют, секция перечисляет её в `wrapper` |
| `products`, `product`, `collection`, `posts` | Полей выбора товаров, товара, коллекции и публикаций у секций пока нет: они появятся вместе с данными магазина в секциях |
| `logo-image` | Это настройка «Настроек темы» «Логотип → Картинка»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['logo-image']` |
| `social-telegram` | Это настройка «Настроек темы» «Социальные сети → Telegram»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-telegram']` |
| `social-vk` | Это настройка «Настроек темы» «Социальные сети → Вконтакте»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-vk']` |
| `social-dzen` | Это настройка «Настроек темы» «Социальные сети → Дзен»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-dzen']` |
| `social-youtube` | Это настройка «Настроек темы» «Социальные сети → Youtube»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-youtube']` |
| `social-tiktok` | Это настройка «Настроек темы» «Социальные сети → TikTok»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-tiktok']` |
| `social-max` | Это настройка «Настроек темы» «Социальные сети → MAX»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-max']` |
| `cart-type` | Это настройка «Настроек темы» «Корзина → Вид корзины»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['cart-type']` |
| `cookie-banner-enabled` | Это настройка «Настроек темы» «Баннер → Баннер cookie»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['cookie-banner-enabled']` |
