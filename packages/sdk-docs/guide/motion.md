Движение в секции делают четырьмя способами. Берите первый подходящий.

| Что нужно | Чем делать |
|---|---|
| Элемент, слова, строки или линии SVG появляются при прокрутке или загрузке страницы | атрибут `data-animate="<пресет>"` — [пресеты](#пресеты-data-animate) |
| Бегущая строка, параллакс фона | классы `animate-marquee`, `parallax` — [styles.md](styles.md#плакат-слои-движение) |
| Смена вида при наведении | классы `hover:` и `transition-*` с `motion-safe:` — [styles.md](styles.md) |
| Своё движение: по нажатию, за курсором, по ответу сервера, по шагам сценария, бесконечное «дыхание» | `ctx.animate`, `ctx.split` и `ctx.on(…, 'pointermove')` из `script.ts` — [ctx.animate](#ctxanimate) |

**Главное, что нужно знать до работы.**

- **`data-animate` играет, только если в «Настройках темы» включено «Появление секций»** (настройка
  `choice-motion-reveal`, по умолчанию `off`). Пока оно выключено, элементы с `data-animate` стоят на месте, как будто
  атрибута нет — в превью конструктора тоже, а у посетителей с «уменьшить движение» его не видно никогда. Включить настройку может
  только мерчант: спросите его, а не включайте сами. `ctx.animate`, `animate-marquee` и `parallax` от этой настройки не
  зависят.
- Чего нет в этой странице, SDK не умеет: `@keyframes`, свой CSS и атрибут `style`, переходы между страницами,
  шейдеры, таймлайн и анимация с привязкой к прокрутке — [чего пока нет](#чего-пока-нет). Свойство вне списка
  `ctx.animate` — сбой `sdk-call-invalid` на витрине.
- В превью конструктора анимации играют сами, когда секция запускается впервые: открыли превью, добавили секцию,
  поменялся её код. Если поменялись только настройки или текст, секция сразу встаёт в последний кадр, чтобы не
  «выезжать» на каждую букву. Увидеть движение ещё раз — кнопка «Проиграть анимации» над превью (вся страница или
  выбранная секция). Раскадровка `merfy_pages look` с `motion` показывает движение по кадрам.

## Пресеты data-animate

`data-animate="<пресет>"` ставится на элемент шаблона. Секция ничего больше не пишет: скрытое начальное состояние и
запуск делает ядро. Параметр `data-delay` (мс, от 0 до 5000) прибавляется к задержке пресета.

<!-- data: motion-presets -->

Как читать таблицу. «Откуда» — где элемент стоит в начале: сдвиг «снизу» значит, что он едет вверх на своё место; `%`
у `words` и `lines` — от высоты слова или строки. «Между элементами» — пауза между элементами одной пачки: детьми у
`appear-group`, буквами, словами, строками, линиями SVG, а также элементами одного пресета, вошедшими в экран в одном
кадре. Пресет считает только `data-animate`; названия, которых нет в таблице, не работают: в консоль уходит строка
«такого пресета нет».

- `letters`, `words` и `lines` разбирают **текст** элемента: разметка внутри (`<em>`, ссылки) пропадает, а полный текст
  остаётся в `aria-label`. Ставьте их на простой заголовок без вложенных тегов и без `set:html`. `words` и `lines`
  поднимают куски из-под маски — так выглядят заголовки на сайтах с Awwwards; `lines` ждёт загрузки шрифтов.
- `mask-up` раскрывает элемент маской снизу вверх — для фото и крупных блоков. `blur-in` проявляет из размытия.
- `draw` прорисовывает линии SVG внутри элемента: путь, линию, круг. Ставьте на `<svg>` или на обёртку вокруг него;
  у линий должен быть штрих (`stroke`), заливка не прорисовывается.
- На один элемент — один пресет.
- «Уменьшить движение»: пресеты не играют, элементы видны сразу.

## ctx.animate

```ts
ctx.animate(el: El | El[], keyframes: Keyframes, options?: AnimateOptions): Animation
```

- `el` — элемент **своей секции** или список таких элементов: `ctx.ref('title')`, `ctx.refs('card')`, результат
  `ctx.split`. Чужой элемент — сбой `sdk-call-invalid` («элемент не из этой секции»).
- `keyframes` — объект «свойство → значение». Значение — одно число или строка (анимация идёт от текущего к нему) или
  массив значений-кадров: `opacity: [0, 1]`, `translate: ['0 24px', '0 0']`. В значении нельзя `url(…)`, кавычки и «\»
  — это отказ `sdk-call-invalid`, как и свойство не из списка. Свойства:

<!-- data: motion-animatable -->

- `options` — все поля необязательны, **время в миллисекундах**:
  - `duration` — длительность, по умолчанию `300`;
  - `delay` — задержка перед началом, по умолчанию `0`;
  - `easing` — кривая: имя из таблицы, массив Безье из четырёх чисел `[0.4, 0, 0.2, 1]` или пружина
    `{ spring: { bounce, duration } }` (`bounce` от 0 до 0,95, по умолчанию 0,25; `duration` по умолчанию 600);
    по умолчанию `'ease-out'`;
  - `stagger` — у списка элементов: каждый следующий стартует на столько позже, по умолчанию `0`;
  - `repeat` — сколько раз проиграть ещё: число или `Infinity`, по умолчанию `0`;
  - `repeatType` — `'loop'` (заново с начала) или `'reverse'` (туда-обратно), по умолчанию `'loop'`.

<!-- data: motion-easings -->

- Результат — `{ finished, stop }`. `finished` — обещание: выполняется, когда анимация (у списка — все) дошла до конца
  **или** была остановлена, и не отклоняется; при `repeat: Infinity` — только после `stop()`. `stop()` останавливает
  анимацию там, где она была.
- В `script.ts` должны встречаться слова `animate`, `ctx.split` или `pointermove`: по ним сборка кладёт код анимаций на
  страницу. Если вызываете через другое имя, страница соберётся без него и вызов упадёт со сбоем `part-unknown`.

Правила, которые ядро исполняет само:

- **Только свои элементы** и только свойства из списка: проверяется при каждом вызове.
- **«Уменьшить движение»** у посетителя — анимация сразу ставит последний кадр, без повтора; `finished` выполняется.
  Писать отдельную проверку `matchMedia` не нужно.
- **Снятие секции** (страница меняется, секцию заменили) останавливает все её анимации.
- **В превью конструктора** — первый запуск секции и смена её кода играют; правка только настроек или текста сразу
  ставит последний кадр; «Проиграть анимации» запускает секцию заново.
- Две анимации одного свойства на одном элементе мешают друг другу: перед новой остановите прежнюю (`stop()`), а для
  сложного движения берите отдельные `translate`, `scale`, `rotate` — они складываются, в отличие от одной строки
  `transform`.
- Ошибку в `ctx.animate` ядро показывает как сбой секции в консоли; остальная страница работает.

## ctx.split

```ts
ctx.split(el: El, by: 'chars' | 'words'): El[]
ctx.split(el: El, by: 'lines'): Promise<El[]>
```

Разбивает текст элемента своей секции на буквы, слова или строки и отдаёт куски — их можно передать в `ctx.animate`
списком. Полный текст уходит в `aria-label` элемента, куски скрыты от экранного диктора (`aria-hidden`). Разметка внутри
элемента пропадает, как у пресета `letters`. Строки считаются по раскладке после загрузки шрифтов, поэтому для
`'lines'` ответ — обещание, а `mount` делают `async`.

## Курсор

```ts
ctx.on('window' | 'document', 'pointermove', (event) => { event.pointer; event.at(el); })
```

- Приходит не чаще раза в кадр, с последним положением курсора.
- `event.pointer` — положение относительно секции: `x`, `y` в px и `px`, `py` — доли ширины и высоты (внутри
  секции — от 0 до 1, за её краем — меньше 0 или больше 1).
- `event.at(el)` — то же относительно любого элемента своей секции; чужой элемент — `null`.
- «Уменьшить движение» событие не выключает: движение за курсором при этой настройке не делайте или делайте едва
  заметным.
- Подписка снимается вместе с секцией. Остальные события `ctx.on` — `keydown`, `keyup`, `scroll`, `resize`,
  `pointerdown`.

## Рецепты

Каждый стоит в `mount(el, ctx)` секции.

**Заголовок по словам из-под маски.** Без скрипта — пресет: `<h2 data-animate="words">{settings.heading}</h2>`
(`lines` — по строкам). Из скрипта, например после нажатия:

```ts
export default defineSection({
  mount(el, ctx) {
    const title = ctx.ref('title');
    if (title === null) return;
    const words = ctx.split(title, 'words');
    ctx.animate(words, { opacity: [0, 1], translate: ['0 0.6em', '0 0'] }, { duration: 800, stagger: 40, easing: 'expo.out' });
  },
});
```

**Магнитная кнопка.** Кнопка тянется к курсору, когда он рядом, и возвращается, когда он ушёл.

```ts
export default defineSection({
  mount(el, ctx) {
    const button = ctx.ref('cta');
    if (button === null) return;
    let move: { stop(): void } | null = null;
    ctx.on('window', 'pointermove', (event) => {
      const p = event.at(button);
      if (p === null) return;
      const near = p.px > -0.3 && p.px < 1.3 && p.py > -0.6 && p.py < 1.6;
      const dx = near ? Math.round((p.px - 0.5) * 18) : 0;
      const dy = near ? Math.round((p.py - 0.5) * 12) : 0;
      move?.stop();
      move = ctx.animate(button, { translate: `${dx}px ${dy}px` }, { duration: 300, easing: 'power2.out' });
    });
  },
});
```

**Наклон карточки за курсором.** Тот же приём, но вместо `translate` — `rotate`: угол от −3 до 3 градусов по доле `px`
внутри карточки, и возврат к `0deg`, когда `at` вышел за 0…1.

**Раскрытие фото маской по нажатию.**

```ts
ctx.animate(photo, { clipPath: ['inset(0% 0% 100% 0%)', 'inset(0% 0% 0% 0%)'], scale: [1.15, 1] }, { duration: 1200, easing: 'expo.out' });
```

**Отклик с пружиной.** Значок корзины подпрыгивает после добавления товара:

```ts
ctx.listen('merfy:cart:add', () => {
  const badge = ctx.ref('badge');
  if (badge !== null) ctx.animate(badge, { scale: [1.4, 1] }, { easing: { spring: { bounce: 0.5, duration: 700 } } });
});
```

**Бесконечное «дыхание».** Плашка «новинка» плавно покачивается:

```ts
ctx.animate(label, { translate: ['0 0', '0 -6px'] }, { duration: 1800, repeat: Infinity, repeatType: 'reverse', easing: 'power2.inOut' });
```

**Карточки по очереди из скрипта.** `ctx.animate(ctx.refs('card'), { opacity: [0, 1], translate: ['0 24px', '0 0'] },
{ duration: 500, stagger: 70, easing: 'power2.out' })`. Скрипт запускается при загрузке страницы, а не при показе секции
на экране, поэтому так делают секции первого экрана; секции ниже — `data-animate="appear-group"` на контейнере: он
дожидается входа в экран.

**Бегущая строка и параллакс** — только классами: `animate-marquee` (`-slow`, `-fast`, `-reverse`) на ряду из двух
одинаковых половин и `parallax` / `parallax-strong` на фоне внутри `overflow-hidden` —
[styles.md](styles.md#плакат-слои-движение).

**Первый экран при загрузке.** Три шага без скрипта: `data-animate="load-1"` на шапке блока, `load-2` на заголовке,
`load-3` на кнопке. Задержки в таблице уже разные, и элементы выходят по очереди.

## Чего пока нет

Ничего из списка писать не нужно: секция упадёт на витрине (`sdk-call-invalid`) или проверка при сохранении её откажет.

- таймлайн (несколько элементов по одному сценарию) и анимация с привязкой к прокрутке, закрепление секции;
- запуск своей анимации из скрипта при входе секции в экран — пока только пресетами `data-animate`;
- анимация чисел (счётчик «0 → 12 000»);
- `@keyframes`, атрибут `style`, `<style>`, классы со своим CSS;
- переходы между страницами (View Transitions), WebGL и шейдеры.

Что делать вместо: сценарий из нескольких шагов — `delay` и `stagger`, следующий шаг — по `finished`; прогресс
прокрутки для полосы — `ctx.page.$scroll` ([страница целиком](script.md#страница-целиком)).
