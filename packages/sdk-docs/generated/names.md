# Имена полей секций

Поле настройки секции — в `settings` файла `section.json` и у типов блоков — называется именем из этого списка, вид поля — из столбца «Виды». Имя не из списка проверка при сохранении не пропускает и выводит ближайшее; для имён из раздела «Нет в словаре» — что вместо них. Подходящего имени нет — секция объявляет своё (раздел «Своё имя секции»). Тот же текст выводит `pnpm merfy section names`.

## Содержимое

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `heading` | `string` | Заголовок | Заголовок секции или блока; у «Страницы» — `<h1>` |
| `subheading` | `string` | Подзаголовок | Строка над или под заголовком |
| `text` | `text`, `richtext` | Текст | Основной текст секции или блока |
| `button-label` | `string` | Текст кнопки | Надпись на кнопке |
| `button-link` | `url` | Ссылка кнопки | Куда ведёт кнопка: страница магазина или свой адрес |
| `button-second-label` | `string` | Текст дополнительной кнопки | Надпись на второй, дополнительной кнопке рядом с основной (`button-label`); пустая — кнопка не выводится |
| `button-second-link` | `url` | Ссылка дополнительной кнопки | Куда ведёт дополнительная кнопка (`button-second-label`): страница магазина или свой адрес |
| `image` | `image` | Картинка | Картинка секции или блока |
| `images` | `image-pair` | Картинки | Две картинки: для компьютера и для телефона |
| `label` | `string` | Подпись | Подпись пункта, ссылки или значка |
| `link` | `url` | Ссылка | Куда ведёт пункт, карточка или картинка |
| `question` | `string` | Вопрос | Вопрос в блоке вопросов и ответов |
| `answer` | `richtext` | Ответ | Ответ на вопрос, текст с форматированием |
| `author` | `string` | Имя | Кто написал отзыв или цитату |
| `caption` | `string` | Подпись | Город, должность или товар под именем или картинкой |
| `rating` | `range` | Оценка | Звёзды отзыва, 0 — без звёзд |
| `video` | `video` | Видео | Видеофайл секции: мерчант загружает его в панели, на витрине он играет в плеере браузера. Ссылки на YouTube и Vimeo не поддерживаются — тег `iframe` в шаблоне запрещён |
| `poster` | `image` | Обложка | Кадр, который виден, пока видео не началось |
| `logo` | `image` | Логотип | Своя картинка логотипа в секции. Логотип магазина — настройка темы `logo-image` |
| `newsletter` | `toggle` | Рассылка | Показать форму подписки на рассылку |
| `menu` | `menu` | Меню | Меню магазина: в ревизии — id меню, в шаблоне — дерево `{ title, items }` |
| `product` | `product` | Выбор товара | Товар магазина: в ревизии — id или адрес товара, в шаблоне — публичные поля товара или null. Пусто — товар страницы на шаблоне «Товар», на других страницах — первый товар магазина |
| `collection` | `collection` | Выбор коллекции | Коллекция магазина: в ревизии — id или адрес, в шаблоне — коллекция с первыми 24 товарами или null. Пусто — коллекция страницы на шаблоне «Коллекция», на других страницах — все товары магазина |
| `posts` | `blog` | Выбор публикации | Блог магазина: в ревизии — id или адрес блога, в шаблоне — блог с 12 новыми записями или null. Пусто — блог страницы на шаблоне «Блог», на других страницах — записи всех блогов |
| `policy` | `policy` | Выбор страницы | Политика магазина: в ревизии — тип (refund, privacy, tos, shipping), в шаблоне — `{ type, title, url, html }` или null. Пусто — политика страницы на шаблоне «Политика», на других страницах — свой текст секции |
| `price` | `hint` | Стоимость | Подсказка вместо поля: цена товара меняется в кабинете, на странице «Товары». Значения нет |
| `per-page` | `range` | Карточки | Сколько карточек на странице списка, от 2 до 24: по ней платформа делит список на страницы |
| `cards` | `range` | Карточки | Сколько карточек показать в секции, от 2 до 24: секция берёт их из выбранной коллекции, список страницы по ним не делится (для этого — `per-page`) |

## Вид

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `heading-size` | `select`, `radio` | Размер заголовка | Размер заголовка: варианты задаёт секция |
| `text-size` | `select`, `radio` | Размер текста | Размер основного текста: варианты задаёт секция |
| `align` | `alignment` | Выравнивание | Выравнивание текста: слева, по центру или справа |
| `content-position` | `select` | Где текст | Где текст поверх картинки: девять мест |
| `image-position` | `radio` | Картинка | Картинка слева или справа от текста |
| `height` | `radio`, `select` | Высота | Высота секции |
| `overlay` | `range` | Затемнение | Затемнение картинки под текстом, в процентах |
| `space` | `padding` | Отступы | Отступы секции сверху и снизу, в пикселях |
| `columns` | `range` | Колонки | Сколько карточек в ряд на компьютере |
| `filter-position` | `radio` | Вид фильтра | Где фильтры списка: `top` — сверху, `side` — сбоку |
| `quick-add` | `select` | Быстрое добавление | Кнопка «В корзину» на карточке списка: варианты вида задаёт секция; кнопка — `data-action="cart.add"` с сочетанием по умолчанию |
| `columns-mobile` | `radio` | Колонки на телефоне | Сколько карточек в ряд на телефоне: одна или две; на компьютере — `columns` |
| `button-style` | `select`, `radio` | Стиль кнопки | Как выглядит кнопка секции: основная (заливка), дополнительная (контур) или ссылка; варианты задаёт секция |
| `text-box` | `toggle` | Контейнер | Плашка под текстом или колонкой: фон схемы, скруглённые углы, поля; выключена — текст прямо на картинке или фоне секции |
| `capitals` | `toggle`, `select` | Заглавные буквы | Что набрано заглавными: переключатель — весь текст секции, выбор — какие части (логотип, меню, заголовки); варианты задаёт секция |
| `text-style` | `select` | Стиль текста | Начертание заголовка и текста секции: обычное или курсив, как на vanilla |
| `image-fit` | `select`, `radio` | Подгонка фото | Как фото ложится в рамку заданных пропорций: `cover` — заполняет рамку и обрезается, `contain` — помещается целиком |
| `swatches` | `select` | Образцы цветов | Образцы цвета товара на карточке: кружки, квадраты или без образцов; цвета — из `card.colors` |
| `caption-case` | `select` | Регистр подписи | Регистр названия на карточке товара: как набрано или заглавными; значение — `normal` или `uppercase` |
| `aspect-ratio` | `select` | Пропорции | Пропорции картинок в сетке |
| `color-scheme` | `color-scheme` | Цветовая схема | Цветовая схема части секции: меню, карточек, плашки с текстом. Схема всей секции — общая настройка |
| `logo-position` | `select` | Положение логотипа | Где логотип в шапке: сверху слева, сверху в центре, слева или по центру |
| `menu-type` | `select` | Тип меню | Боковое, выпадающее или расширенное меню |
| `active-link` | `select`, `radio` | Активный пункт меню | Как отмечен пункт меню открытой страницы, например подчёркиванием: варианты задаёт секция |
| `layout` | `select`, `radio` | Раскладка | Раскладка той же секции: в одну или две строки, число и порядок колонок; варианты задаёт секция, у каждого — своя разметка в шаблоне |

## Поведение

| Имя | Виды | Подпись | О чём |
|---|---|---|---|
| `paging` | `select` | Как листать | Листание списка: `pages` — номера страниц, `more` — «Показать ещё», `scroll` — бесконечная прокрутка; значение — параметр `data-paging` поведения `catalog` |
| `next-photo` | `toggle` | Следующее фото при наведении | Второе фото карточки при наведении — параметр `data-hover-next` поведения `card-photos` |
| `favorite` | `toggle` | Избранное | Сердечко «В избранное» на карточке: `data-action="favorites.toggle"`; показано, пока избранное включено в «Настройках темы» (`wishlist-enabled`) |
| `sold-out` | `select` | Распроданное | Значения вариантов, которых нет в наличии: `show` — показывать, `hide` — прятать |
| `open-first` | `toggle` | Первый открыт | Первый вопрос раскрыт при загрузке |
| `autoplay` | `toggle` | Листать сами | Слайды меняются без нажатия |
| `video-autoplay` | `toggle` | Автозапуск | Видео начинает играть само, без звука: браузеры не запускают видео со звуком без нажатия |
| `video-muted` | `toggle` | Без звука | Видео играет без звука; поле показано при выключенном `video-autoplay` — с автозапуском звука нет всегда |
| `video-loop` | `toggle` | Повтор | Закончившись, видео начинается сначала |
| `interval` | `range` | Интервал | Секунд между слайдами; поле показано при `autoplay` |
| `zoom` | `radio` | Увеличение | Увеличение главного фото товара: `hover` — лупа при наведении, `click` — окно по нажатию; значение — параметр `data-mode` поведения `zoom` |

## Своё имя секции

Нужного имени в списке нет — секция объявляет своё в ключе `names` файла `section.json`, а поле берёт его в `id`. Свои имена — только этой секции и её блоков; словарь они не меняют.

```json
{
  "names": { "sku": { "kinds": ["toggle"], "label": "Артикул", "about": "Показать артикул товара в карточке", "asks": ["артикул"] } },
  "settings": [
    { "id": "sku", "label": "Показывать артикул", "setting": { "kind": "toggle", "default": false } }
  ]
}
```

- `kinds` — виды полей, для которых имя годится; поле с этим именем другого вида проверка не пропустит (`setting-name-kind`).
- `label` — подпись имени, до 32 знаков.
- `about` — одной строкой, о чём настройка, от трёх знаков: как `О чём` в таблицах выше.
- `asks` — слова, которыми мерчант просит об этом.
- Имя — строчные латинские буквы и цифры через одиночный дефис, до 32 знаков; не из раздела «Нет в словаре» (`name-own-invalid`) и не повтор имени словаря (`name-own-in-dictionary`).
- Своих имён в секции — не больше 10 (`names-limit`).
- Есть подходящее имя в словаре — бери его, а не своё.

## Нет в словаре

| Имена | Что вместо |
|---|---|
| `variant`, `mode`, `view`, `design`, `style` | Другая раскладка той же секции — поле `layout`; секция другого назначения — новая секция. Мелкие отличия — поля `image-position`, `columns`, `height` |
| `color`, `colour`, `background`, `background-color`, `text-color` | Своего цвета у поля нет: цвет секции — общая настройка «Цветовая схема», цвет части секции — поле `color-scheme` |
| `font`, `font-family`, `font-size`, `font-weight`, `typography` | Шрифт и насыщенность — токены темы `font-heading` и `font-body`; размер — поля `heading-size` и `text-size` |
| `margin`, `padding-top`, `padding-bottom`, `gap`, `spacing` | Отступы секции — общая настройка «Отступы» в `wrapper`; внутри секции — классы словаря |
| `container`, `full-width` | Ширина содержимого секции — общая настройка «Ширина» (`width` в `wrapper`); своего поля ширины у секции нет |
| `show-*`, `hide-*`, `visible`, `hidden` | Показать или скрыть часть секции — блок с `limit: 1`: его скрывают в конструкторе |
| `scheme`, `padding`, `sticky`, `width` | Общая настройка секции: в `settings` её не объявляют, секция перечисляет её в `wrapper` |
| `products` | Выбора нескольких товаров руками нет, как на проде: товары — из коллекции, поле `collection`; один товар — поле `product` |
| `logo-image` | Это настройка «Настроек темы» «Логотип → Картинка»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['logo-image']` |
| `social-telegram` | Это настройка «Настроек темы» «Социальные сети → Telegram»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-telegram']` |
| `social-vk` | Это настройка «Настроек темы» «Социальные сети → Вконтакте»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-vk']` |
| `social-dzen` | Это настройка «Настроек темы» «Социальные сети → Дзен»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-dzen']` |
| `social-youtube` | Это настройка «Настроек темы» «Социальные сети → Youtube»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-youtube']` |
| `social-tiktok` | Это настройка «Настроек темы» «Социальные сети → TikTok»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-tiktok']` |
| `social-max` | Это настройка «Настроек темы» «Социальные сети → MAX»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['social-max']` |
| `cart-type` | Это настройка «Настроек темы» «Корзина → Вид корзины»; секция её читает: `"uses": ["theme"]`, в шаблоне `theme['cart-type']` |
