Движение в секции делают несколькими способами. Берите первый подходящий.

| Что нужно | Чем делать |
|---|---|
| Элемент, слова, строки или линии SVG появляются при прокрутке или загрузке страницы | атрибут `data-animate="<пресет>"` — [пресеты](#пресеты-data-animate) |
| Бегущая строка, параллакс фона, покачивание, блик, медленное вращение, появление от прокрутки классом | классы `animate-marquee`, `parallax`, `animate-float`, `animate-shimmer`, `animate-spin-slow`, `scroll-reveal` — [styles.md](styles.md#плакат-слои-движение) |
| Смена вида при наведении | классы `hover:` и `transition-*` с `motion-safe:` — [styles.md](styles.md) |
| Своё движение: по нажатию, за курсором, по ответу сервера, по шагам сценария, бесконечное «дыхание» | `ctx.animate`, `ctx.split` и `ctx.on(…, 'pointermove')` из `script.ts` — [ctx.animate](#ctxanimate) |
| Анимация идёт вместе с прокруткой, закреплённая секция | `ctx.scroll` — [ctx.scroll](#ctxscroll) |
| Своя анимация, когда элемент вошёл в экран | `ctx.inView` — [ctx.inView](#ctxinview) |
| Несколько элементов по одному сценарию, счётчик «0 → 12 000», отдельные `x` и `y` | `"uses": ["lib:motion"]` и `ctx.lib.motion` — [полный Motion](#полный-motion-libmotion) |
| Плавная инерционная прокрутка всей страницы, прокрутка к месту, свои анимации на скорости прокрутки | `"uses": ["lib:lenis"]` и `ctx.lib.lenis` — [плавная прокрутка](#плавная-прокрутка-liblenis) |
| Плавный переход между страницами, фото карточки «перелетает» на страницу товара | настройка темы `choice-page-transition` и атрибут `data-vt` — [переход между страницами](#переход-между-страницами) |

**Главное, что нужно знать до работы.**

- **`data-animate` играет, только если в «Настройках темы» включено «Появление секций»** (настройка
  `choice-motion-reveal`, по умолчанию `off`). Пока оно выключено, элементы с `data-animate` стоят на месте, как будто
  атрибута нет — в превью конструктора тоже, а у посетителей с «уменьшить движение» его не видно никогда. Включить
  настройку может только мерчант: спросите его, а не включайте сами. `ctx.animate`, `ctx.scroll`, `ctx.lib.motion` и
  классы движения от этой настройки не зависят.
- Чего нет в этой странице, SDK не умеет: `@keyframes`, свой CSS и атрибут `style`, шейдеры —
  [чего пока нет](#чего-пока-нет). Свойство у `ctx.animate` — любое, но в значении нельзя адресов и выхода из значения
  (таблица ниже); нарушение — сбой `sdk-call-invalid` на витрине.
- В превью конструктора анимации играют сами, когда секция запускается впервые: открыли превью, добавили секцию,
  поменялся её код. Если поменялись только настройки или текст, секция сразу встаёт в последний кадр, чтобы не
  «выезжать» на каждую букву: `ctx.animate` и `ctx.lib.motion` — в последнем кадре, `ctx.scroll` прокрутку не слушает,
  `ctx.lib.lenis` — прокрутка без сглаживания.
  Увидеть движение ещё раз — кнопка «Проиграть анимации» над превью (вся страница или выбранная секция). Раскадровка
  `merfy_pages look` с `motion` показывает движение по кадрам.

## Пресеты data-animate

`data-animate="<пресет>"` ставится на элемент шаблона. Секция ничего больше не пишет: скрытое начальное состояние и
запуск делает ядро. Параметр `data-delay` (мс, от 0 до 5000) прибавляется к задержке пресета.

<!-- data: motion-presets -->

Как читать таблицу. «Откуда» — где элемент стоит в начале: сдвиг «снизу» значит, что он едет вверх на своё место; `%`
у `words` и `lines` — от высоты слова или строки. «Между элементами» — пауза между элементами одной пачки: детьми у
`appear-group`, буквами, словами, строками, линиями SVG, а также элементами одного пресета, вошедшими в экран в одном
кадре. Пресет считает только `data-animate`; названия, которых нет в таблице, не работают: в консоль уходит строка
«такого пресета нет».

- `letters`, `words` и `lines` разбирают **текст** элемента: разметка внутри (`<em>`, ссылки) пропадает, а полный текст
  остаётся в `aria-label`. Ставьте их на простой заголовок без вложенных тегов и без `set:html`. `words` и `lines`
  поднимают куски из-под маски — так выглядят заголовки на сайтах с Awwwards; `lines` ждёт загрузки шрифтов.
- `mask-up` раскрывает элемент маской снизу вверх — для фото и крупных блоков. `blur-in` проявляет из размытия.
- `draw` прорисовывает линии SVG внутри элемента: путь, линию, круг. Ставьте на `<svg>` или на обёртку вокруг него;
  у линий должен быть штрих (`stroke`), заливка не прорисовывается.
- На один элемент — один пресет.
- «Уменьшить движение»: пресеты не играют, элементы видны сразу.

## ctx.animate

```ts
ctx.animate(el: El | El[], keyframes: Keyframes, options?: AnimateOptions): Animation
```

- `el` — элемент **своей секции** или список таких элементов: `ctx.ref('title')`, `ctx.refs('card')`, результат
  `ctx.split`. Чужой элемент — сбой `sdk-call-invalid` («элемент не из этой секции»).
- `keyframes` — объект «свойство → значение». Свойство — **любое свойство CSS** в camelCase, как в JavaScript
  (`opacity`, `translate`, `clipPath`, `backgroundColor`, `WebkitMaskPosition`), или переменная CSS `--имя`. Значение —
  одно число или строка (анимация идёт от текущего к нему) или массив значений-кадров: `opacity: [0, 1]`,
  `translate: ['0 24px', '0 0']`. Имя с дефисом (`background-color`) — отказ. В значении нельзя частей из таблицы — это
  отказ `sdk-call-invalid`; правило одно для `ctx.animate`, пресетов и `ctx.lib.motion`:

<!-- data: motion-forbidden -->

- Переменные CSS: у `ctx.animate` плавно меняются только зарегистрированные через `@property`, остальные встают в
  новое значение скачком. Свой `@property` секция написать не может, поэтому свою переменную плавно меняет полный
  Motion (`ctx.lib.motion`) — у него анимируется любая переменная.
- `options` — все поля необязательны, **время в миллисекундах**:
  - `duration` — длительность, по умолчанию `300`;
  - `delay` — задержка перед началом, по умолчанию `0`;
  - `easing` — кривая: имя из таблицы, массив Безье из четырёх чисел `[0.4, 0, 0.2, 1]` или пружина
    `{ spring: { bounce, duration } }` (`bounce` от 0 до 0,95, по умолчанию 0,25; `duration` по умолчанию 600);
    по умолчанию `'ease-out'`;
  - `stagger` — у списка элементов: каждый следующий стартует на столько позже, по умолчанию `0`;
  - `repeat` — сколько раз проиграть ещё: число или `Infinity`, по умолчанию `0`;
  - `repeatType` — `'loop'` (заново с начала) или `'reverse'` (туда-обратно), по умолчанию `'loop'`.

<!-- data: motion-easings -->

- Результат — `{ finished, stop }`. `finished` — обещание: выполняется, когда анимация (у списка — все) дошла до конца
  **или** была остановлена, и не отклоняется; при `repeat: Infinity` — только после `stop()`. `stop()` останавливает
  анимацию там, где она была. Результат можно отдать в `ctx.scroll` — тогда анимацию крутит прокрутка.
- В `script.ts` должны встречаться слова `animate`, `ctx.split` или `pointermove`: по ним сборка кладёт код анимаций на
  страницу. Если вызываете через другое имя, страница соберётся без него и вызов упадёт со сбоем `part-unknown`.

Правила, которые ядро исполняет само:

- **Только свои элементы** и только безопасные значения: проверяется при каждом вызове.
- **«Уменьшить движение»** у посетителя — анимация сразу ставит последний кадр, без повтора; `finished` выполняется.
  Писать отдельную проверку `matchMedia` не нужно.
- **Снятие секции** (страница меняется, секцию заменили) останавливает все её анимации.
- **В превью конструктора** — первый запуск секции и смена её кода играют; правка только настроек или текста сразу
  ставит последний кадр; «Проиграть анимации» запускает секцию заново.
- Две анимации одного свойства на одном элементе мешают друг другу: перед новой остановите прежнюю (`stop()`), а для
  сложного движения берите отдельные `translate`, `scale`, `rotate` — они складываются, в отличие от одной строки
  `transform`.
- Ошибку в `ctx.animate` ядро показывает как сбой секции в консоли; остальная страница работает.

## ctx.split

```ts
ctx.split(el: El, by: 'chars' | 'words'): El[]
ctx.split(el: El, by: 'lines'): Promise<El[]>
```

Разбивает текст элемента своей секции на буквы, слова или строки и отдаёт куски — их можно передать в `ctx.animate`
списком. Полный текст уходит в `aria-label` элемента, куски скрыты от экранного диктора (`aria-hidden`). Разметка внутри
элемента пропадает, как у пресета `letters`. Строки считаются по раскладке после загрузки шрифтов, поэтому для
`'lines'` ответ — обещание, а `mount` делают `async`.

## ctx.scroll

```ts
ctx.scroll(target: El, run: Animation | ((progress: number) => void), options?: { offset?: string[] }): Stop
```

Привязывает движение к прокрутке: пока `target` проходит через экран, анимация идёт от начала к концу и обратно, если
листают назад.

- `target` — элемент своей секции, по проходу которого считается прогресс; часто сама секция (`el` из `mount`).
- `run` — ответ `ctx.animate` или `ctx.lib.motion` (`timeline`, `tween`, `animate`): анимация встаёт на паузу и
  двигается прокруткой. Или функция: получает прогресс от 0 до 1 не чаще раза в кадр. Любой другой объект — сбой
  `sdk-call-invalid`.
- `offset` — где прогресс 0 и где 1: пары «край цели край экрана», края `start`, `center`, `end`, доля от 0 до 1 или
  число с `px`, `%`, `vh`, `vw`. По умолчанию `['start end', 'end start']` — от появления цели внизу экрана до ухода
  вверх. У закреплённой секции — `['start start', 'end end']`: прогресс идёт, пока она стоит.
- Ответ — функция отписки. Снятие секции отписывает само.
- **«Уменьшить движение»** и запуск секции в превью после правки настроек или текста — прокрутку не слушает: анимация
  уже на последнем кадре, функция один раз получает `1`.
- В `script.ts` должно быть слово `scroll`: по нему сборка кладёт код на страницу (до 4 КБ).

## ctx.inView

```ts
ctx.inView(el: El | El[], fn: (el: El) => void | (() => void), options?: { amount?, margin?, once? }): Stop
```

Зовёт `fn`, когда элемент своей секции вошёл в экран; что `fn` вернёт функцией, вызывается, когда элемент ушёл. Так
запускают свою анимацию при показе, а не при загрузке страницы.

- `amount` — какая доля элемента в экране считается входом: `'some'` (по умолчанию, хоть пиксель), `'all'` или число
  от 0 до 1.
- `margin` — отступ области экрана, 1–4 значения `px` или `%`, как у CSS: `'0px 0px -20% 0px'` — вход на 20 % выше
  нижнего края.
- `once: true` — только первый вход, потом отписка.
- Список элементов — каждый со своим входом. Браузер без `IntersectionObserver` зовёт `fn` сразу.
- Работает во всех режимах; анимации, которые запускает `fn`, сами учитывают «уменьшить движение» и превью.
- Ответ — функция отписки; снятие секции отписывает само. В `script.ts` должно быть слово `inView`.

## Полный Motion (lib:motion)

Сценарии, которых нет у `ctx.animate`, даёт библиотека из каталога SDK. Секция просит её в `section.json`:

```json
{ "uses": ["lib:motion"] }
```

и получает `ctx.lib.motion`. Импортировать библиотеку в `script.ts` не нужно и нельзя — код кладёт сборка и только на
страницы, где стоит такая секция. Имя не из каталога — отказ `lib-unknown` при сохранении; `ctx.lib.motion` без
`"lib:motion"` в `uses` — тоже `lib-unknown`. Каталог:

<!-- data: motion-libraries -->

```ts
ctx.lib.motion.timeline(segments: [El | El[], Keyframes, options?][], options?: { delay?, repeat?, repeatType? }): Playback
ctx.lib.motion.tween(from: number, to: number, options: { duration?, delay?, easing? } | undefined, onUpdate: (value: number) => void): Playback
ctx.lib.motion.animate(el: El | El[], keyframes: Keyframes, options?: AnimateOptions): Playback
```

- `timeline` — несколько элементов по одному сценарию. Сегмент — `[элемент, кадры, параметры]`, параметры — как у
  `ctx.animate` и ещё `at`: число — мс от начала таймлайна, `'<'` — вместе с прошлым сегментом, `'+200'` и `'-200'` —
  через или за столько мс от конца прошлого. Без `at` сегмент идёт сразу после прошлого.
- `tween` — число от `from` до `to`: `onUpdate` получает каждое промежуточное значение (счётчик, процент, цена).
- `animate` — как `ctx.animate`, плюс отдельные части трансформации: `x`, `y`, `z`, `rotateX`, `rotateY`, `rotateZ`,
  `scaleX`, `scaleY`, `skewX`, `skewY`, и плавные переменные CSS без `@property`.
- `Playback` — `{ finished, stop, play, pause, time }`: `finished` и `stop` — как у `ctx.animate`, `pause()` и `play()`
  ставят на паузу и продолжают, `time` — текущее время в мс, его можно читать и задавать. Любой `Playback` можно отдать
  в `ctx.scroll`.
- Правила те же, что у `ctx.animate`: только свои элементы, проверка значений, «уменьшить движение» и запуск в превью после
  правки настроек или текста — сразу последний кадр (`onUpdate` у `tween` получает `to`), снятие секции — остановка.

## Плавная прокрутка (lib:lenis)

Инерционную прокрутку всей страницы, как на сайтах студий, включает сама секция: в `section.json`

```json
{ "uses": ["lib:lenis"] }
```

— и на странице с этой секцией колесо и `scrollTo` прокручивают плавно ([Lenis](https://github.com/darkroomengineering/lenis)).
Настройки темы для этого нет: прокрутку включает автор секции, когда на неё завязаны его анимации. Экземпляр один на
страницу: его заводит первая секция с `"lib:lenis"`, и он живёт, пока на странице есть хоть одна такая секция. Lenis
двигает настоящую прокрутку окна, поэтому `ctx.scroll`, `ctx.inView`, `ctx.lib.motion` и пресеты `data-animate`
работают с ним как обычно.

```ts
ctx.lib.lenis.onScroll(fn: (state: { scroll, limit, progress, velocity, direction }) => void): Stop
ctx.lib.lenis.scrollTo(target: number | El, options?: { offset?, duration?, immediate? }): void
ctx.lib.lenis.stop(): void
ctx.lib.lenis.start(): void
ctx.lib.lenis.configure(settings: { lerp?, duration? }): boolean
```

- `onScroll` — каждый кадр прокрутки: `scroll` — px от верха, `limit` — самая нижняя прокрутка, `progress` — 0…1 от
  всей страницы, `velocity` — px за кадр со знаком, `direction` — `1` вниз, `-1` вверх. Снятие секции отписывает само.
- `scrollTo` — к числу px от верха страницы или к элементу своей секции; `offset` — px к цели (`-80` — остановиться
  выше на 80 px, под шапкой), `duration` — мс, `immediate: true` — сразу. Чужой элемент — сбой `sdk-call-invalid`.
- `stop()` запирает прокрутку страницы (прелоадер, своё полноэкранное меню), `start()` отпирает. Запрет держится, пока
  его держит хоть одна секция; снятие секции снимает и её запрет.
- `configure({ lerp, duration })` — плавность для всей страницы: `lerp` — доля оставшегося пути за кадр, 0.01…1 (по
  умолчанию 0.1, меньше — плавнее), `duration` — мс прокрутки колесом вместо `lerp`, 100…5000. Применяет первая
  вызвавшая секция, у остальных ответ `false` — страница одна, плавность у неё тоже одна.
- «Уменьшить движение» и запуск в превью после правки настроек или текста — сглаживания нет: прокрутка нативная,
  `onScroll` срабатывает от обычной прокрутки, `scrollTo` — сразу.
- Стили, которые Lenis просит ставить (`scroll-behavior: auto`, `height: auto` у `<html>` и `<body>`), ставит SDK —
  своего CSS не нужно; `scroll-behavior: smooth` темы с Lenis не спорит. Окна поверх страницы (корзина, меню) и области
  с прокруткой внутри секции прокручиваются как обычно.

## Переход между страницами

Витрина — обычные страницы, но браузер может плавно сменить одну на другую (View Transitions между документами).
Включает это настройка темы **«Переход между страницами»** — `choice-page-transition`: `none` (по умолчанию, обычный
переход), `fade` (затухание) или `slide` (сдвиг с затуханием). Выбирает её мерчант в «Настройках темы»: спросите его.
Секции для этого ничего писать не нужно.

- **Общий элемент.** Атрибут `data-vt="<имя>"` с одним и тем же именем на двух страницах: фото в карточке каталога и
  фото на странице товара — `data-vt={`product-${product.id}`}`. При переходе фото «перелетает» с места на место.
  `view-transition-name` ставит SDK; на странице имя получает только первый элемент, на уходящей — только элемент в
  ссылке, по которой ушли (или вне ссылок). Знаки кроме букв, цифр, `_` и `-` в имени становятся `-`.
- Браузер без поддержки — обычный переход. «Уменьшить движение» — без перехода. В превью конструктора переходов нет.

## Курсор

```ts
ctx.on('window' | 'document', 'pointermove', (event) => { event.pointer; event.at(el); })
```

- Приходит не чаще раза в кадр, с последним положением курсора.
- `event.pointer` — положение относительно секции: `x`, `y` в px и `px`, `py` — доли ширины и высоты (внутри
  секции — от 0 до 1, за её краем — меньше 0 или больше 1).
- `event.at(el)` — то же относительно любого элемента своей секции; чужой элемент — `null`.
- «Уменьшить движение» событие не выключает: движение за курсором при этой настройке не делайте или делайте едва
  заметным.
- Подписка снимается вместе с секцией. Остальные события `ctx.on` — `keydown`, `keyup`, `scroll`, `resize`,
  `pointerdown`.

## Рецепты

Каждый стоит в `mount(el, ctx)` секции.

**Заголовок по словам из-под маски.** Без скрипта — пресет: `<h2 data-animate="words">{settings.heading}</h2>`
(`lines` — по строкам). Из скрипта, например после нажатия:

```ts
export default defineSection({
  mount(el, ctx) {
    const title = ctx.ref('title');
    if (title === null) return;
    const words = ctx.split(title, 'words');
    ctx.animate(words, { opacity: [0, 1], translate: ['0 0.6em', '0 0'] }, { duration: 800, stagger: 40, easing: 'expo.out' });

```

**Закреплённая секция с таймлайном от прокрутки.** Секция высотой в три экрана, внутри — слой, закреплённый `sticky`;
пока секцию листают, заголовок уезжает, фото раскрывается, подпись проявляется. `section.json`: `"uses": ["lib:motion"]`.

```astro
<div class="relative h-[300vh]" data-ref="track">
  <div class="sticky top-0 flex h-svh items-center justify-center overflow-hidden">
    <h2 class="font-heading text-7xl" data-ref="title">{settings.heading}</h2>
    {settings.image && <img class="absolute inset-0 -z-10 size-full object-cover" data-ref="photo" src={settings.image} alt="" />}
    <p class="absolute bottom-8 text-lg opacity-0" data-ref="caption">{settings.text}</p>
  </div>
</div>
```

```ts
export default defineSection({
  mount(el, ctx) {
    const track = ctx.ref('track');
    const title = ctx.ref('title');
    const photo = ctx.ref('photo');
    const caption = ctx.ref('caption');
    if (track === null || title === null || photo === null || caption === null) return;
    const story = ctx.lib.motion.timeline([
      [title, { y: [0, -160], opacity: [1, 0] }, { duration: 1000 }],
      [photo, { clipPath: ['inset(30% 30% 30% 30%)', 'inset(0% 0% 0% 0%)'], scale: [1.2, 1] }, { duration: 1000, at: '<' }],
      [caption, { opacity: [0, 1] }, { duration: 400 }],
    ]);
    ctx.scroll(track, story, { offset: ['start start', 'end end'] });
  },
});
```

Длительности здесь — доли пути прокрутки, а не время: весь таймлайн растягивается на проход секции.

**Плавная прокрутка, параллакс и полоса прогресса.** Секция включает плавную прокрутку страницы, фото в ней едет
медленнее страницы (`ctx.scroll`), а тонкая полоса сверху показывает, сколько страницы пролистано (`onScroll`).
`section.json`: `"uses": ["lib:lenis", "lib:motion"]`.

```ts
export default defineSection({
  mount(el, ctx) {
    const photo = ctx.ref('photo');
    const bar = ctx.ref('bar');
    if (photo === null || bar === null) return;
    ctx.lib.lenis.configure({ lerp: 0.08 });
    // Параллакс: проход секции через экран крутит сдвиг фото.
    const drift = ctx.lib.motion.animate(photo, { y: [-60, 60] }, { duration: 1000, easing: 'linear' });
    ctx.scroll(el, drift);
    // Полоса прогресса всей страницы: время анимации — доля пролистанного.
    const fill = ctx.lib.motion.animate(bar, { scaleX: [0, 1] }, { duration: 1000, easing: 'linear' });
    fill.pause();
    ctx.lib.lenis.onScroll(({ progress }) => {
      fill.time = progress * 1000;
    });
  },
});
```

У полосы в шаблоне — `origin-left`, у фото — запас по высоте (`scale-110` внутри `overflow-hidden`), чтобы при сдвиге не
открывался край.

**Счётчик «0 → 12 000» при входе в экран.** `section.json`: `"uses": ["lib:motion"]`.

```ts
export default defineSection({
  mount(el, ctx) {
    const value = ctx.ref('value');
    if (value === null) return;
    const to = Number(ctx.settings.number ?? 0);
    ctx.inView(value, () => {
      ctx.lib.motion.tween(0, to, { duration: 1500, easing: 'expo.out' }, (n) => value.text(Math.round(n).toLocaleString('ru-RU')));
    }, { once: true });
  },
});
```

В шаблоне сразу стоит итоговое число — его видят поисковики, превью и посетители с «уменьшить движение».

**Своя анимация при входе в экран.** Карточки секции ниже первого экрана выезжают по очереди, когда до них долистали:

```ts
export default defineSection({
  mount(el, ctx) {
    const cards = ctx.refs('card');
    ctx.inView(el, () => {
      ctx.animate(cards, { opacity: [0, 1], translate: ['0 24px', '0 0'] }, { duration: 500, stagger: 70, easing: 'power2.out' });
    }, { once: true, amount: 0.3 });
  },
});
```

До входа карточки видны на своих местах: скрывать их заранее классом `opacity-0` нельзя — в превью и без скрипта они
остались бы невидимыми. Нужно скрытое начало — берите `data-animate="appear-group"` на контейнере.

**Переход между страницами.** В «Настройках темы» мерчант выбирает «Переход между страницами» — `fade` или `slide`.
Чтобы фото товара перелетало из каталога на страницу товара, у фото в карточке и у главного фото на странице товара
ставят одно имя:

```astro
<img src={product.image} alt={product.title} data-vt={`product-${product.id}`} />
```

**Магнитная кнопка.** Кнопка тянется к курсору, когда он рядом, и возвращается, когда он ушёл.

```ts
export default defineSection({
  mount(el, ctx) {
    const button = ctx.ref('cta');
    if (button === null) return;
    let move: { stop(): void } | null = null;
    ctx.on('window', 'pointermove', (event) => {
      const p = event.at(button);
      if (p === null) return;
      const near = p.px > -0.3 && p.px < 1.3 && p.py > -0.6 && p.py < 1.6;
      const dx = near ? Math.round((p.px - 0.5) * 18) : 0;
      const dy = near ? Math.round((p.py - 0.5) * 12) : 0;
      move?.stop();
      move = ctx.animate(button, { translate: `${dx}px ${dy}px` }, { duration: 300, easing: 'power2.out' });
    });
  },
});
```

**Наклон карточки за курсором.** Тот же приём, но вместо `translate` — `rotate`: угол от −3 до 3 градусов по доле `px`
внутри карточки, и возврат к `0deg`, когда `at` вышел за 0…1.

**Карточки по очереди из скрипта при загрузке.** `ctx.animate(ctx.refs('card'), { opacity: [0, 1], translate: ['0 24px', '0 0'] },
{ duration: 500, stagger: 70, easing: 'power2.out' })` — для секций первого экрана; секциям ниже — `ctx.inView` (рецепт
выше) или `data-animate="appear-group"` на контейнере.

**Бегущая строка, параллакс, появление от прокрутки** — только классами: `animate-marquee` (`-slow`, `-fast`,
`-reverse`) на ряду из двух одинаковых половин, `parallax` / `parallax-strong` на фоне внутри `overflow-hidden`,
`scroll-reveal` (`-up`, `-fade`) на блоке — [styles.md](styles.md#плакат-слои-движение).

**Первый экран при загрузке.** Три шага без скрипта: `data-animate="load-1"` на шапке блока, `load-2` на заголовке,
`load-3` на кнопке. Задержки в таблице уже разные, и элементы выходят по очереди.

## Чего пока нет

Ничего из списка писать не нужно: секция упадёт на витрине (`sdk-call-invalid`) или проверка при сохранении её откажет.

- `@keyframes`, атрибут `style`, `<style>`, классы со своим CSS, свой `@property`;
- импорт библиотек в `script.ts` — только каталог SDK через `"uses": ["lib:<имя>"]`;
- WebGL и шейдеры.

Что делать вместо: своё бесконечное движение — `ctx.animate` с `repeat: Infinity` или готовые классы
([styles.md](styles.md#плакат-слои-движение)); переменная CSS, которая должна меняться плавно, — `ctx.lib.motion.animate`.
