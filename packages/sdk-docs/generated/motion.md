# Анимации

> SDK 1 · документация 1.37.0 · 2026-11-12

Движение в секции делают четырьмя способами. Берите первый подходящий.

| Что нужно | Чем делать |
|---|---|
| Элемент плавно появляется при прокрутке или загрузке страницы | атрибут `data-animate="<пресет>"` — [пресеты](#пресеты-data-animate) |
| Бегущая строка, параллакс фона | классы `animate-marquee`, `parallax` — [styles.md](styles.md#плакат-слои-движение) |
| Смена вида при наведении | классы `hover:` и `transition-*` с `motion-safe:` — [styles.md](styles.md) |
| Своё движение по событию: нажатие, ответ сервера, шаг сценария, стопка карточек по очереди | `ctx.animate` из `script.ts` — [ctx.animate](#ctxanimate) |

**Главное, что нужно знать до работы.**

- **`data-animate` играет, только если в «Настройках темы» включено «Появление секций»** (настройка
  `choice-motion-reveal`, по умолчанию `off`). Пока оно выключено, элементы с `data-animate` стоят на месте, как будто
  атрибута нет, а в превью и у посетителей с «уменьшить движение» его не видно никогда. Включить настройку может
  только мерчант: спросите его, а не включайте сами. `ctx.animate`, `animate-marquee` и `parallax` от этой настройки не
  зависят.
- Всё, чего нет в таблицах ниже, SDK пока не умеет: `clip-path`, маски, `filter` (размытие), `@keyframes`, свой CSS и
  атрибут `style`, переходы между страницами, шейдеры, анимацию от прокрутки с привязкой к кадру. Не пишите это:
  свойство вне списка `ctx.animate` — сбой `sdk-call-invalid` на витрине. Берите ближайшее из этой страницы.
- В превью конструктора появления `data-animate` не играют, а `ctx.animate` сразу ставит последний кадр. Так мерчант не
  видит движения до публикации; проверять его нужно на витрине.

## Пресеты data-animate

`data-animate="<пресет>"` ставится на элемент шаблона. Секция ничего больше не пишет: скрытое начальное состояние и
запуск делает ядро. Параметр `data-delay` (мс, от 0 до 5000) прибавляется к задержке пресета.

| Пресет | Что движется | Откуда | Время, мс | Кривая | Между элементами, мс | Когда играет |
|---|---|---|---|---|---|---|
| `appear` | сам элемент | прозрачность 0 → 1, 24 px снизу | 600 | `power2.out` | 80 | когда элемент поднялся над нижним краем окна на 15 % высоты окна, один раз; уже видимый при загрузке играет сразу |
| `appear-group` | каждый прямой потомок элемента | прозрачность 0 → 1, 24 px снизу | 500 | `power2.out` | 70 | когда элемент поднялся над нижним краем окна на 15 % высоты окна, один раз; уже видимый при загрузке играет сразу |
| `appear-side` | вся секция (ближайшая `merfy-section`) | прозрачность 0 → 1, 32 px слева у чётной секции `main`, справа у нечётной, 24 px снизу | 700 | `power3.out` | — | когда элемент поднялся над нижним краем окна на 15 % высоты окна, один раз; уже видимый при загрузке не анимируется |
| `fade-up` | сам элемент | прозрачность 0 → 1, 20 px снизу | 650 | `material` | — | когда элемент поднялся над нижним краем окна на 36 px, один раз; уже видимый при загрузке играет сразу |
| `slide-down` | сам элемент | прозрачность 0 → 1, 16 px сверху | 550 | `material` | — | когда элемент поднялся над нижним краем окна на 36 px, один раз; уже видимый при загрузке играет сразу |
| `load-1` | сам элемент | прозрачность 0 → 1, 16 px сверху | 700 | `material` | — | при загрузке страницы, через 50 мс |
| `load-2` | сам элемент | прозрачность 0 → 1, 20 px снизу | 700 | `material` | — | при загрузке страницы, через 150 мс |
| `load-3` | сам элемент | прозрачность 0 → 1, 20 px снизу | 700 | `material` | — | при загрузке страницы, через 280 мс |
| `letters` | каждая буква текста элемента | прозрачность 0 → 1, 0,4 em снизу | 500 | `power2.out` | 30 | когда элемент поднялся над нижним краем окна на 15 % высоты окна, один раз; уже видимый при загрузке играет сразу |

Как читать таблицу. «Откуда» — где элемент стоит в начале: сдвиг «снизу» значит, что он едет вверх на своё место.
«Между элементами» — пауза между элементами одной пачки: детьми у `appear-group`, буквами у `letters`, а также
элементами одного пресета, вошедшими в экран в одном кадре. Пресет считает только `data-animate`; названия, которых
нет в таблице, не работают: в консоль уходит строка «такого пресета нет».

- `letters` разбирает **текст** элемента на буквы: разметка внутри (`<em>`, ссылки) пропадает, а полный текст остаётся в
  `aria-label`. Ставьте его на простой заголовок без вложенных тегов и без `set:html`.
- Пресет двигает прозрачность и сдвиг. Масштаба, поворота и размытия у пресетов нет: такое движение пишут через
  `ctx.animate`.
- На один элемент — один пресет.
- «Уменьшить движение»: пресеты не играют, элементы видны сразу.

## ctx.animate

```ts
ctx.animate(el: El, keyframes: Keyframes, options?: AnimateOptions): Animation
```

- `el` — элемент **своей секции**: `ctx.ref('title')`, `ctx.refs('card')[0]`, элемент из `list`. Чужой элемент —
  сбой `sdk-call-invalid` («элемент не из этой секции»).
- `keyframes` — объект «свойство → значение». Значение — одно число или строка (анимация идёт от текущего к нему) или
  массив значений-кадров: `opacity: [0, 1]`, `translate: ['0 24px', '0 0']`. В значении нельзя `url(…)`, кавычки и «\»
  — это отказ `sdk-call-invalid`, как и свойство не из списка. Свойства:

| Свойство | Значение |
|---|---|
| `opacity` | прозрачность, число от 0 до 1 |
| `transform` | вся трансформация строкой: `translateY(24px) scale(0.9)`; для одного вида движения лучше отдельные свойства ниже |
| `translate` | сдвиг: `0 24px` (по x и по y); отдельно от `scale` и `rotate`, их можно анимировать одновременно |
| `scale` | масштаб: число `0.9` или `1.1 1.1` |
| `rotate` | поворот: `15deg` |
| `color` | цвет текста: `#c9a227`, `rgb(…)` |
| `backgroundColor` | цвет фона |
| `borderColor` | цвет рамки |
| `width` | ширина: число (px) или строка с единицей `50%` |
| `height` | высота |
| `maxHeight` | предельная высота; так раскрывают блок: `[0, 240]` |

- `options` — все поля необязательны, **время в миллисекундах**:
  - `duration` — длительность, по умолчанию `300`;
  - `delay` — задержка перед началом, по умолчанию `0`;
  - `easing` — кривая: имя из таблицы или массив Безье из четырёх чисел `[0.4, 0, 0.2, 1]`, по умолчанию `'ease-out'`.

| Имя | Кривая Безье | Где |
|---|---|---|
| `'linear'` | `[0, 0, 1, 1]` | без ускорения |
| `'ease-out'` | `[0, 0, 0.58, 1]` | слово CSS `ease-out`; умолчание `ctx.animate` |
| `'decelerate'` | `[0, 0, 0.2, 1]` | выезд панелей, класс Tailwind `ease-out` |
| `'material'` | `[0.4, 0, 0.2, 1]` | стандартная кривая «материал»: `fade-up`, `slide-down`, `load-*` |
| `'power2.out'` | `[0.33, 1, 0.68, 1]` | мягкое замедление в конце: `appear`, `appear-group`, `letters` |
| `'power3.out'` | `[0.25, 1, 0.5, 1]` | резче замедление: `appear-side` |
| `'power2.in'` | `[0.32, 0, 0.67, 0]` | мягкий разгон: уход элемента |
| `'power3.in'` | `[0.5, 0, 0.75, 0]` | резкий разгон |
| `'power2.inOut'` | `[0.65, 0, 0.35, 1]` | разгон и торможение |
| `'back.out'` | `[0.33, 1.36, 0.66, 1]` | небольшой перелёт и возврат: «пружинка» |

- Результат — `{ finished, stop }`. `finished` — обещание: выполняется, когда анимация дошла до конца **или** была
  остановлена, и не отклоняется. `stop()` останавливает анимацию.
- Повтора, зацикливания и пружины нет. Бесконечное движение (бегущая строка) — класс `animate-marquee`.
- Слово `animate` должно встречаться в `script.ts` (вызов `ctx.animate(…)`): по нему сборка кладёт код анимаций на
  страницу. Если вызываете через другое имя, страница соберётся без него и вызов упадёт со сбоем `part-unknown`.

Правила, которые ядро исполняет само:

- **Только свои элементы** и только свойства из списка: проверяется при каждом вызове.
- **«Уменьшить движение»** у посетителя — анимация сразу ставит последний кадр, `finished` выполняется. Писать отдельную
  проверку `matchMedia` не нужно.
- **Снятие секции** (страница меняется, секцию заменили) останавливает все её анимации.
- **В превью конструктора** — сразу последний кадр, а не движение.
- Две анимации одного свойства на одном элементе мешают друг другу. Поэтому для сложного движения
  берите отдельные `translate`, `scale`, `rotate` (они складываются), а не одну строку `transform`.
- Ошибку в `ctx.animate` ядро показывает как сбой секции в консоли; остальная страница работает.

## Рецепты

Рецепты только на том, что есть сейчас. Каждый стоит в `mount(el, ctx)` секции.

**Подъём и масштаб отдельными свойствами.** Кнопка «в корзину» отвечает на успех: сдвиг и масштаб идут одновременно,
потому что это разные свойства.

```ts
export default defineSection({
  mount(el, ctx) {
    ctx.listen('merfy:cart:add', () => {
      const badge = ctx.ref('badge');
      if (badge === null) return;
      ctx.animate(badge, { translate: ['0 -8px', '0 0'], scale: [1.3, 1] }, { duration: 400, easing: 'back.out' });
    });
  },
});
```

**Карточки по очереди из скрипта.** Задержка растёт с номером карточки. Скрипт запускается при загрузке страницы, а не
при показе секции на экране, поэтому так делают секции в первом экране. Секции ниже — `data-animate="appear-group"` на
контейнере: он дожидается входа в экран.

```ts
export default defineSection({
  mount(el, ctx) {
    ctx.refs('card').forEach((card, index) => {
      ctx.animate(
        card,
        { opacity: [0, 1], translate: ['0 24px', '0 0'] },
        { duration: 500, delay: index * 70, easing: 'power2.out' },
      );
    });
  },
});
```

**Нажатие.** На кнопке или карточке: `ctx.on` принимает только `keydown`, `keyup`, `scroll`, `resize` и `pointerdown`, а
`event.inside(el)` говорит, пришло ли нажатие изнутри элемента. Поэтому отклик на нажатие писать можно, а на
**наведение и положение курсора нельзя**: нет событий `pointermove` и `pointerenter`, координат у события нет, и поэтому
«магнитной» кнопки сделать нельзя. Отклик на наведение — классами `hover:` ([styles.md](styles.md)).

```ts
export default defineSection({
  mount(el, ctx) {
    const button = ctx.ref('cta');
    if (button === null) return;
    ctx.on('document', 'pointerdown', (event) => {
      if (event.inside(button)) ctx.animate(button, { scale: [0.94, 1] }, { duration: 220, easing: 'back.out' });
    });
  },
});
```

**Бегущая строка.** Только классом: ряд из двух одинаковых половин, `animate-marquee` (`-slow`, `-fast`, `-reverse`),
пауза под курсором `hover:animate-paused`. Из скрипта бесконечного повтора нет. Образец с разметкой — в
[styles.md](styles.md#плакат-слои-движение).

**Параллакс.** Классом `parallax` или `parallax-strong` на фоне внутри `overflow-hidden`. Положение прокрутки для своей
логики даёт `"uses": ["page"]` и стор `ctx.page.$scroll` (доля прокрутки страницы, целое от 0 до 100) —
[страница целиком](script.md#страница-целиком); он годится для полосы прогресса через `cssVar`, а не для плавного
движения слоёв.

**Заголовок по буквам.** Пресет `letters`: `<h1 data-animate="letters">{settings.heading}</h1>`. Одна строка простого
текста, без разметки внутри. Из скрипта разбить текст на буквы нельзя.

**Первый экран при загрузке.** Три шага без скрипта: `data-animate="load-1"` на шапке блока, `load-2` на заголовке,
`load-3` на кнопке. Задержки в таблице уже разные, и элементы выходят по очереди.

## Чего пока нет

Ничего из списка ниже писать не нужно: секция упадёт на витрине (`sdk-call-invalid`) или проверка при сохранении её откажет.

- свойства `clipPath`, `filter`, `strokeDashoffset`, `letterSpacing`, `borderRadius` в `ctx.animate`;
- пружина, повтор, список элементов и `stagger` одним вызовом, таймлайн, анимация от прокрутки;
- `@keyframes`, атрибут `style`, `<style>`, классы со своим CSS;
- переходы между страницами (View Transitions), WebGL и шейдеры;
- разбиение текста на слова и строки.

Что делать вместо: маску-раскрытие заменяют `maxHeight` и `opacity`, размытие — `opacity`, пружину — кривой `'back.out'`,
шаг за шагом по списку — `delay: index * 70`.
