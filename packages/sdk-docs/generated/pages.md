# Страницы

> SDK 1 · документация 1.2.0 · 2026-10-28

## Группы страницы

Страница магазина — три списка секций: шапка, сама страница и подвал. Куда секцию можно поставить — ключ `groups`
в `section.json`: `["header"]`, `["page"]`, `["footer"]` или несколько. Нет ключа — только на страницу.

- `limit` — сколько экземпляров секции в одном списке.
- `"removable": false` — секцию нельзя удалить, её ошибка рендера — ошибка сборки магазина.
- `newPage` — id поля вида `string`: секция ставится на новую страницу, в поле пишется имя страницы.
- `autoPlace` — только у секций расширений, значение `"product"`: когда мерчант включает расширение, секция сама
  встаёт на страницу сразу после секции с местом блоков `product` (кнопка «В корзину» товара), если её экземпляра в
  магазине ещё нет. Мерчант двигает и убирает её как любую; убранная встаёт снова только при следующем включении.

## Особые страницы

Главная, каталог, товар, корзина и другие страницы платформы — особые: у них постоянные id, мерчант их не удаляет.
Своих страниц у магазина сколько угодно. Поля «тип страницы» нет: секция не знает, на какой странице стоит, и
одинаково работает на любой.

## Заголовки

На странице один `<h1>` — главный заголовок страницы. Секция, которая открывает страницу, ставит его у своего
заголовка; в остальных секциях заголовки — `<h2>` и ниже. Не уверен, первая ли секция на странице, — `<h2>`.
