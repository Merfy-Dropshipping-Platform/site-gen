# Лимиты

> SDK 1 · документация 1.18.0 · 2026-10-29

Пределы, которые проверка секции применяет при сохранении. Числа — из констант проверки.

## Файлы

- Файлов в секции — не больше 50.
- Один файл — не больше 64 КБ.
- Все файлы вместе — не больше 256 КБ.

## Поля и блоки

- Полей секции — не больше 20.
- Полей типа блока — не больше 16.
- Типов блоков — не больше 8, блоков — не больше 50.
- Вариантов списка — от 2 до 10.
- Подпись — не длиннее 32 знаков, подпишись — 120.

## Шаблон и скрипт

- Вложенность шаблона — не глубже 256.
- Скрипт после сжатия: предупреждение — от 10 КБ, предел — 50 КБ.

## Проверка

- Время проверки секции — до 10 с.
- Память процесса проверки — до 256 МБ.
