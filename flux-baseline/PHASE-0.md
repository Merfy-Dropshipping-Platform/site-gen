# Фаза 0 — базовая линия Flux

Дата: 2026-07-29. Изменений в коде темы не вносилось (только инструменты в `flux-baseline/`).

## Итог фазы

**Gate 0 пройден.** Эталон снимается побайтово воспроизводимо во всех четырёх viewport.

**Главная находка: эталон ОДИН, а не три.** Вывод Task 12 о «трёх взаимно противоречащих
источниках правды» неверен и снят:

| источник | статус |
|---|---|
| репо `flux-theme` @ `e29b7092` | **= HEAD ветки main**, репо никуда не уезжал |
| живой `flux.merfy.ru` | **побайтово реализует этот же коммит** (сверено по Hero: `h-[380px] sm:h-[480px] lg:aspect-[1920/810]` → замер 380/480/540/810) |
| PNG-референс spec-079 (бежевые сумки) | просто устаревший артефакт другой демо-витрины — не конкурирующая правда, а мусор |

Практическое следствие: **сверять надо исходники, а не пиксели.** Исходная сверка
показывает конкретное разошедшееся значение (`gap-6` вместо `gap-8`), пиксельная —
только «здесь что-то не так». Пиксельный diff остаётся как финальный гейт Фазы 6,
но ведущим инструментом быть не должен.

## Динамические области — сравнивать напрямую нельзя

| область | почему |
|---|---|
| промо-полоса | `data-promo-expires=1798761599000` (31.12.2026) — после этой даты скрипт удаляет полосу целиком; замер после этой даты даст другую геометрию всей страницы |
| цены, «Нет в наличии», бейдж «Скидка» | зависят от товаров тенанта |
| состав Popular / Collections / Gallery | зависит от каталога тенанта |
| корзина, wishlist | клиентское состояние |
| `/data/products.json`, `/data/collections.json` | у нас пишутся только когда у тенанта ≥1 товар; в эталоне товары статические |
| источник картинок | эталон — статика `/images/4x/*.webp`; у нас — MinIO |
| `_astro/*.hash.css|js` | хеши сборки различаются всегда |

Эти области в Фазе 6 маскируются; геометрические anchors проверяются отдельно от картинки.

### Hero — разбор пилота

| свойство | эталон | наш порт | вердикт |
|---|---|---|---|
| высота полотна | `h-[380px] sm:h-[480px] lg:aspect-[1920/810]` | `h-[280px] sm:h-[360px] lg:h-[480px]` | **ошибка транскрипции: 380 → 280**; комментарий в порте ссылается на «эталон Hero.astro:28», где стоит 380 |
| цвет заголовка | `text-[#000000]` | `--color-heading` со значением по умолчанию **белым** | дефолт токена неверный |
| подзаголовок | 12→14px, uppercase, `#999999` | 14→16px, **без uppercase**, белый | размер, регистр и цвет |
| кнопка | `h-12`, `rounded-[4px]`, `bg-[#1e2952]`, `font-light` | `h-14`, `rounded-…6px`, `bg-black`, `font-normal` | все четыре значения |
| затемнение фона | градиент в белый снизу от 85% | сплошной `bg-black/30` | лишний слой |
| gap контента | `gap-8 lg:gap-10` | `gap-6 lg:gap-10` | mobile/tablet |
| отступы обёртки | только `px-4` | `px-4 py-8 md:px-20 md:py-10 2xl:px-80` | лишние |
| кадрирование фото | `w-[200%] top-[-10.8%] sm:w-[160%] lg:w-full` | `object-cover object-center inset-0` | другой алгоритм кадрирования |

Важная оговорка: часть «лишнего» в порте — **законное оживление**, а не дефект.
Литералы намеренно заменены на токены (`rgb(var(--color-heading,…))`), чтобы цветосхемы
конструктора могли ими управлять. Дефект в другом: **значение по умолчанию внутри
`var()` не равно эталонному литералу**. Правильная форма — `var(--color-heading, 0_0_0)`,
`var(--radius-button, 4px)`. Это ровно случай «у свойства есть владелец = color scheme»
из Фазы 2 дока.

## Что осталось незакрытым в Фазе 0

**«Список отличий локального Flux» (пиксельный) не снят.** Причина: локальный стенд не
поднят — sites-service не запущен, `nginx-sites` на :8088 раздаёт только заглушку.
Инфраструктура при этом жива: postgres:5432, MinIO:9010, RabbitMQ:5672, nginx:8088.

Это не блокер: сверка исходников (`SOURCE-DIFF.md`) даёт более точный список отличий,
чем пиксельный diff, и её хватает, чтобы начать Фазу 3. Пиксельный набор `local`
снимается тем же `capture.mjs --label local` сразу после Gate 1 и сравнивается
командой `report.mjs reference local`.
