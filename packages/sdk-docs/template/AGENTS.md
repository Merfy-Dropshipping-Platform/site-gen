# Секция витрины Merfy

SDK 1. Документация — https://gateway.merfy.ru/api/storefront/sdk/llms.txt
Читай её, а не память: SDK новый. Версия и дата документации — в её шапке.

1. Новая секция — начни с этого шаблона. Меняешь секцию магазина — сначала прочитай её файлы
   (GET …/sections/<name>/source).
2. section.json — поля и блоки. Имена полей — только из names.md. Нужного имени нет — возьми то,
   что назвала проверка. Подходящего имени нет — объяви своё в `names` секции (names.md, «Своё имя секции»).
3. template.astro — разметка. Классы — только из словаря (styles.md). style, <style> и <script> нельзя.
   Код — по code.md: значение настройки — в атрибут data-*, вид — вариантами классов data-[…]:; без ?: внутри ?:
   и повторённых условий. Предупреждения taste-* исправь до сохранения.
4. script.ts — только если на странице что-то меняется после загрузки. В нём — defineSection и ctx;
   window, document, fetch, setTimeout нельзя (script.md).
5. Корзина, избранное, кто вошёл (customer), вход и кабинет (auth), данные магазина — модули SDK по uses (modules.md).
   Шапке хватит customer: auth добавляет на страницу код входа. Других запросов у секции нет.
6. Готовое поведение data-behavior — по умолчанию. Нужно другое — напиши своё в script.ts.
7. Проверь секцию. Ошибка называет файл, строку, код и правильное значение: исправь это место
   и проверь снова. Три попытки; не вышло — покажи мерчанту ответ проверки целиком.
8. <h1> — по правилу pages.md.
9. Корзина, вход, поиск — секции с ролью, в магазине по одной: меняй саму секцию или её поля, копию не делай.
10. Чужие секции не трогай.
11. Форма «Контакты» пока не отправляет сообщения — скажи об этом мерчанту и предложи контакты ссылками.
